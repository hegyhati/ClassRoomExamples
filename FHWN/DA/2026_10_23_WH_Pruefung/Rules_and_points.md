# General rules

Only submit the 1-3 C files that you worked on, and nothing else.

## Immediate failing of the exam

The **WHOLE EXAM** is immediately negatively graded if for **ANY** of the submitted C files:
 - the compilation fails
 - the compiled executable segfaults with the provided test data.

Only upload C files, that you have tested thourougly. 

## Point reduction

If the solution for an exercise leaks memory, the awarded points for that exercise are halved.

## Allowed resources

No external resource is allowed to be used. The manpage of useful functions to be used will be provided. 

If the essence of the exercise (e.g. sorting) is done by a library function (e.g. `qsort`), the exercise will be graded with 0 points. If you are unsure whether the usage of a library function is allowed or not, ask one of the supervisors.

## Additional functions / structs

You are always free to declare & define any number of new functions, structs, etc.
