# Parenthesis checker on steroids
 
 - Write two functions based on the ideas of the `counter` and `couple_checker` that checks whether a string contains a correct parenthesis sequence from `[`,`]`, `(`, `)`, `{`, `}` characters.
 - Think about what kind of inputs would be interesting for testing. 
 - Test how these algorithms scale on those examples.
 - Plot the results, draw conclusions, and try to reason about them.
