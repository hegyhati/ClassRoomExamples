# Informationen zu den Programmieraufgaben - Wiederholungsprüfung Zusatzteil

Die im Zusatzteil erreichten Punkte werden gemeinsam mit den bereits erzielten Punkten der Wiederholungsprüfung für die Gesamtbeurteilung herangezogen.

Die **Advanced** Aufgabenstellung kann nach der erfolgreichen Umsetzung der **Basic** Aufgabenstellungen bearbeitet werden.

**Abgabe:** die gegebenen .py Files, keine zusätzlichen Files.
